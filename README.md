## Featured projects

### Digital Gaming Marketplace

**Difmark-inspired personal project · May 2026 – Oct. 2026**

A digital gaming marketplace connecting product discovery, seller listings, and a buyer checkout flow.

- Product search/filtering, seller profiles, and persistent shopping carts.
- Supabase authentication, listing creation, image uploads, and listing status management.
- Stripe **test-mode** checkout, server-side payment verification, and buyer order history.
- A **282-test Vitest suite** and GitHub Actions for lint, type checks, tests, and production builds.

**Built with:** Next.js · React · TypeScript · Supabase · PostgreSQL · Tailwind CSS · Stripe

**[Live demo](https://gamingmarketplace.click)** &nbsp; / &nbsp; **[Source code](https://github.com/gh-phduy/gaming-marketplace)**

### Quiz Flash

**Vocabulary-learning PWA · Jul. 2026 – Sep. 2026**

A vocabulary practice app with six study modes: flashcards, matching, typing, listening, speaking, and quizzes.

- Spaced repetition and difficulty-based review scheduling.
- Saved study progress and review history with Supabase/PostgreSQL.
- Progress dashboards, activity heatmaps, and speech synthesis/recognition for pronunciation practice.

**Built with:** Next.js · React · TypeScript · Supabase · Zustand · Recharts · Tailwind CSS · Cloudflare

**[Live demo](https://quizflash.click)** &nbsp; / &nbsp; **[Source code](https://github.com/gh-phduy/quiz-flash)**
